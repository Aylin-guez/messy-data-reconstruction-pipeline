# Messy Data Reconstruction Pipeline

From disconnected and inconsistent datasets to a unified master dataset.


This project demonstrates how multiple inconsistent datasets can be cleaned, normalized, matched and reconstructed into a single source of truth.

The pipeline processes customer records, sales transactions and support tickets coming from different sources with inconsistent naming conventions and formats.

The final output includes:

- Data cleaning
- Name normalization
- Entity matching
- Sales aggregation
- Ticket aggregation
- Reconciliation metrics
- Master customer dataset
